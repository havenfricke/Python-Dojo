### EXTENSIBILITY / INHERTIANCE, REGULAR EXPRESSIONS, GETTERS, AND SETTERS

- Remember that classes are essentially object creators for object-oriented programming languages
- They are for modeling data

- With the SOLID principles, after S - single-responsibility principle comes the O - Open-closed principle
- The open-closed principle states that classes and modules should be open for extensibility and closed for modification

### CLASSES

- When classes are written, they should be in such a way that allows them to stand alone without further modification
- Furthermore they should be written in such a way that allows them to be extended / inherited
- Extending classes in programming is a way to access a class's features without modifying or calling directly to the class
- Inheriting a class is extending a class

### REGULAR EXPRESSIONS

- A regular expression or regex is a sequence of characters that defines a search pattern for string type data
- They are primarily used for input validation or data validation
- If you are working with emails, there is a regex that can check that the format of an email is correct
- If you are working with phone numbers, there is a regex that can check that the format of a phone number is correct
- If you want to exclude certain words or phrases, there is a regex to do so.

### GETTERS / SETTERS

- Getters and setters are a way to handle data within a class and provide utility around allowed and disallowed values within the class
- With getters and setters we can define what information is allowed to be modified and retrieved
- A class with both a get and a set has read and write permissions
- A class with only a getter is read-only
- A class with a setter is write-only
