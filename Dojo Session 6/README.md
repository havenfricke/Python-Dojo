### FOR LOOPS, ARRAYS, AND ALGORITHMS

### FOR LOOPS

- The for loop is one of the most crucial tools in programming
- It is primarily used to iterate through data
- For loops can be used on arrays, dictionaries, strings, and essentially any multi-property data
- They utilize simple counting to look at data indecies

### ARRAYS

- Arrays are exactly as they sound, an array of something
- Arrays can only be one type of data
- An array of strings can only handle strings
- An array of integers can only handle integers
- An array of floats can only handle floats
- Arrays always count from 0 up.
- The first index in an array is always the zeroth index behind the scenes

### ALGORITHMS

- Algorithms sound scary, but everything you have learned so far in the Dojo can be used to make algorithms
- By definition, it is a set of instructions or rules to complete or solve a specific task
- For loops, array, if's, switches, and while loops are all the makings of an algorithm
- Classes assist in modeling and instantiating the data that algorithms process
