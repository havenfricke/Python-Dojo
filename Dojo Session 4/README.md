### CLASSES, WHILE LOOP, TRY EXCEPT LOOP, AND INPUTS

### CLASSES
- Classes are a way of instancing data and creating utility in object-oriented programming
- Functions encapsulated or inside of classes are referred to as methods
- Classes use constructors to determine and alias data, similar to variables
- Classes are blueprints to objects, python is an object oriented language.
- Think of a class as an object contructor or printing press with the ability for custom utility
- Again, being thinking of the S in SOLID principles - Single-responsibility principle
- A class use only have one responsibility in the context of its use

### WHILE LOOPS
- While loops will run until a condition evaluates to false or falsy 
- A While loop would run if a value is 1, but if 0 it would not run
- These loops are most commonly used for terminal or CLI programs and they are used in game engines

### TRY-EXCEPT or TRY-CATCH
- Code or logic that is encapsulated or within a try-except or try-catch block will attempt to run
- If an error occurs, the except portion will handle the error
- If it succeeds, the except or catch is ignored and the program runs successfully

### INPUTS
- Inputs are used to receive dynamic values from a user
- They create the ability to use different values from user input using the terminal
