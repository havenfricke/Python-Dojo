### DATA TYPES, VARIABLES, ARITHMETIC OPERATORS, AND FUNCTIONS.

### DATA TYPES

Data types are the foundation of any coding language:

- Some languages are strictly typed like C, C++, C#, and TypeScript
- Untyped or dynamic languages include JavaScript, Python, Ruby, PHP, Perl
- Learning code in an untyped language is easiest so python is perfect although typed languages are generally more secure.
- This is due to the requirements of typed languages - they need to know what type of data is being declared, used, etc.

The general and most commonly used types in computer science are:

- String (A word written with a speakable human language)
- Character (One Letter or symbol that Strings are derived form)
- Integer (A number without a decimal point)
- Boolean (false / true, 0 / 1)
- Float / Double (A Number with a decimal point. A float uses less memory to store the fractional values after the decimal, a double stores more)

### VARIABLES

The gist of variables are:

- Variables are values of a data type you declare in any program that you want to be stored.
- Variables will allocate a small portion of memory on the computer.
- When a variable is declared then used in a computer program, you are "pointing" to a value or place in memory.

### FUNCTIONS

- A function is code where logic happens. This is where the execution of a program is ran. They are also things you declare in a computer program similar to variables.
- Functions may have parameters, arguments, and a return value (more on that later).

### ARITHMETIC OPERATORS

Operators are add, subtract, multiply, divide etc. They can be used on more than just numbers. All the arithmetic operators are:
- (=) equals
- (+) add
- (-) subtract
- (*) multiply
- (/) divide
- (%) modulo <-- this is the remainder after two numbers divide.
- (**) exponent <-- squared, cubed etc.
