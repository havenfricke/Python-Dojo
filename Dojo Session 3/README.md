### MODULE IMPORTS AND EXPORTS

- To begin creating an application, we have to start thinking about separation of concerns
- In software architecture, there are principles that are helpful in organizing your application to keep code clean and understandable
- Those are called the SOLID principles -> https://en.wikipedia.org/wiki/SOLID
- For now, we are focused on the "S" of SOLID or the "single-responsibility" principle
- This principle states that programs you write should have one responsibility in their purpose
- Importing and exporting python modules becomes crucial if we want to adhere to this principle
- A module is a term interchangeable with a program file (like exports.py)
- A program file can technically be considered a module once it is being used elsewhere in the program via import / export
